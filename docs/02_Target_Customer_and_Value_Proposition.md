# 02. Target Customer & Value Proposition

## 1차 구매 고객 (Primary Buyer)

**중견기업 HR / 조직개발 / 경영지원 / AX 추진 담당자**

- 규모: 매출 약 1,500억~1조 원, 직원 300~2,000명 수준
- 의사결정: HR팀장~임원, 또는 경영지원실/전략기획실
- 실제 사용자: HR 담당자 + 일부 팀장

### 왜 중견기업인가
| 구분       | 대기업          | 중견기업              | 중소기업     |
|------------|-----------------|-----------------------|--------------|
| AX 압력    | 매우 높음       | 높음                  | 상대적으로 낮음 |
| 예산·인력  | 충분            | 제한적                | 매우 부족    |
| 기존 솔루션| 대형 SI/글로벌 적합 | 너무 무겁거나 비쌈   | 도입 어려움  |
| 기회       | 낮음            | **높음**              | 낮음         |

## Value Proposition (최종)

**한 줄**  
중견기업 HR이 경영진의 AX 지시를  
“무엇을, 어떤 순서로, 누구와 함께 바꿔야 하는지”로 구조화하고,  
조직 마찰과 준비도를 데이터로 보여주며,  
경영진·IT·현업과 책임을 명확히 나눌 수 있게 하는  
**근거 기반 의사결정 지원 시스템**.

**포지셔닝**  
- HR에게 AX 책임을 더 지우는 도구가 아니다.
- HR이 전략에서 배제되지 않도록 **근거를 제공**하고,  
  부서 간 책임을 나누며, 성과를 증명할 수 있게 하는 도구다.

### Value Proposition Canvas 요약

**Customer Job**  
경영진의 AX 지시를 사람·업무·조직 차원의 실행 계획으로 전환하고,  
조직 준비도와 구조적 장애 요인을 진단하며,  
부서 간 책임을 조정하고, 실제 성과를 경영진에게 증명해야 한다.

**Pain**  
전략 수립 단계에서는 충분히 참여하지 못하면서,  
교육·변화관리·성과 보고의 실행과 실패 책임은 떠안고 있으며,  
“무엇을 어떻게 바꿔야 하는지” 판단할 공통 데이터와 프레임이 없다.

**Gain**  
조직 상태와 업무 영향을 객관적으로 설명하고,  
경영진·IT·현업과 책임을 명확히 분담하며,  
AX 활동을 생산성·업무 변화·인력 전환 성과로 보고할 수 있다.

**Pain Relievers & Gain Creators**  
- 구조적 장벽(평가 지표 충돌, 중간관리자 태도, 역할 불명확 등)을 데이터로 드러냄
- 경영진 보고용 한 장 리포트 제공
- 실행 우선순위(Work Redesign) + 실행 지표 제시
- HR·IT·현업의 역할 분담 제안
- 액션의 실행 여부와 진행을 확인할 수 있는 방법 제공
