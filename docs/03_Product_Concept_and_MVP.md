# 03. Product Concept & MVP Scope (고도화 반영)

## 제품 콘셉트

**이름 (가칭)**: AX Fit  
**한 줄 정의**: 중견기업 HR을 위한 AX 조직 마찰 진단 및 업무 재설계 의사결정 지원 시스템

**핵심 레이어**
1. **Friction Diagnostic**  
   경영진 / 중간관리자 / 실무자 레이어별 인식·기대·실제 행동 갭과 구조적 장벽 측정

2. **Work Redesign Guide**  
   진단 결과를 바탕으로 우선 재설계할 태스크/역할 영역 + 구체적 권고 + 실행 지표 제시

3. **Executive One-pager**  
   경영진 회의용 한 장 리포트 (현재 상태 + 핵심 문제 + 권고 액션 + 역할 분담 + 30일 액션)

4. **개인 마이크로 액션** (보조)  
   진단 참여자에게 역할별 즉시 적용 가능한 작은 액션 + 실행 체크 제공

## 고도화된 MVP 범위

### Must-have
- **회사 맥락 입력** (업종, 직원 규모, AX 진행 단계, 추진 조직)
- 3개 레이어 진단 (경영진 / 중간관리자 / 실무자)
- Friction Map (응답 + 맥락 기반 동적 점수)
- Work Redesign 우선순위 3~4개 (구체적 파일럿 형태 + 역할 분담 + 성공 지표 포함)
- 경영진용 한 장 리포트 (템플릿 기반, 맥락 반영, PDF 다운로드)
- 개인 결과 + 고도화된 마이크로 액션
- 액션별 실행 지표 정의
- 지표 수집 방법 (액션 보드 + 체크리스트 수준)
- 데모 데이터로도 설득력 있는 결과 제공
- 반응형 웹 (모바일 기본 대응)

### Later (Post-MVP)
- 회사 단위 계정 + 데이터 저장/비교
- Slack/Teams 연동 및 리마인더
- LLM 실시간 동적 문장 생성 고도화
- 팀장용 상세 Enablement 모듈
- 동종 업계 벤치마크
- 실제 생산성·피로도 추적
- 유료 플랜 및 관리자 대시보드

## 성공 기준 (MVP)
- 심사위원/잠재 고객이 “이거면 HR이 경영진 앞에서 이야기할 수 있겠다”고 느끼는가
- 중견기업 HR이 “우리 회사 상황과 비슷하다”고 공감하는가
- “교육 더 시키기”와 명확히 다른 접근이라는 점이 드러나는가
- 회사 맥락이 결과에 실제로 반영되는가
- 30분 안에 전체 플로우 시연 가능
- 액션에 “누가 / 무엇을 / 어떻게 확인할지”가 포함되어 있는가
