# AX Fit — 전체 개발 명세서 (Integrated Spec)

**버전**: 고도화 MVP (v4)  
**최종 업데이트**: 2026-07-17  
**목적**: 다른 개발 도구/개발자가 이 문서만 보고 프로토타입을 구현할 수 있도록 모든 결정 사항을 통합

---

## 0. 한 줄 요약

중견기업 HR이 경영진의 AX 지시를  
“무엇을, 어떤 순서로, 누구와 함께 바꿔야 하는지”로 구조화하고,  
조직 마찰과 준비도를 데이터로 보여주며,  
경영진·IT·현업과 책임을 명확히 나눌 수 있게 하는  
**근거 기반 의사결정 지원 시스템**.

---

## 1. 문제와 기회

### 핵심 문제
한국 중견기업은 AI를 ‘도구 도입 + 교육’으로 접근하기 때문에  
직원 피로는 증가하고, 중간관리자는 형식적으로 움직이며,  
실제 업무 방식·역할·성과 지표는 거의 변하지 않는다.

### 기회
중견기업은 AX 압박은 받지만 대형 컨설팅/무거운 플랫폼을 쓰기엔 부담스럽고,  
기존 HR Tech만으로는 “왜 안 바뀌는지 + 어떻게 바꿔야 하는지”를 해결하지 못한다.

### Non-goals
- 개인 프롬프트 추천 도구 (입구로만 사용)
- 무거운 엔터프라이즈 HR 시스템
- AI 교육 콘텐츠 플랫폼
- AI 에이전트 자체 개발·운영

---

## 2. 타깃과 Value Proposition

### 1차 구매 고객
중견기업 HR / 조직개발 / 경영지원 / AX 추진 담당자  
(직원 300~2,000명 규모)

### Value Proposition
중견기업 HR이 경영진의 AX 지시를  
“무엇을, 어떤 순서로, 누구와 함께 바꿔야 하는지”로 구조화하고,  
조직 마찰과 준비도를 데이터로 보여주며,  
경영진·IT·현업과 책임을 명확히 나눌 수 있게 하는  
근거 기반 의사결정 지원 시스템.

**포지셔닝**: HR에게 책임을 더 지우는 도구가 아니라,  
근거를 주고 책임을 나눌 수 있게 하는 도구.

## 3. 제품 콘셉트와 MVP 범위

### 핵심 레이어
1. Friction Diagnostic (3개 레이어 진단)
2. Work Redesign Guide (우선순위 + 구체적 권고)
3. Executive One-pager (경영진용 한 장 리포트)
4. 개인 마이크로 액션 (보조)

### MVP Must-have
- 회사 맥락 입력 (업종, 규모, AX 단계, 추진 조직)
- 3개 레이어 진단
- Friction Map (동적)
- Work Redesign 우선순위 (구체화 + 실행 지표)
- 경영진용 한 장 리포트 (템플릿 기반)
- 개인 결과 + 마이크로 액션
- 액션 실행 지표 정의 + 수집 방법

### Later
회사 계정, 데이터 저장/비교, Slack 연동, LLM 고도화, 벤치마크 등

1. 랜딩
2. 회사 맥락 입력

6. 조직 결과 (핵심)

   - 경영진용 리포트 미리보기 + PDF
   - HR 활용 가이드

## 5. 진단 문항 (요약)

- **경영진**: 8문항 (목표 명확성, 기대 성과, 장애물, 실제 변화, HR 참여, 중간관리자, 성과 지표, 우선 영역)
- **중간관리자**: 10문항 (활용 비중, 미활용 이유, 연결성, 독려 부담, 평가 차별, 지표 방향, AI 대체 가능 업무, 교육 후 변화, 기대 차이, 필요 지원)
- **실무자**: 10문항 (사용 빈도, 어려움, 교육 도움, 평가 영향, 상사 장려, 불안, 도움 받을 업무, 여건 부족 이유, 목적 전달, 가장 먼저 바뀌어야 할 것)

(전체 문항은 기존 `04_Diagnostic_Questionnaire.md` 참고)

## 6. 결과 로직 상세

### 6.1 Friction 요인 (5개)
- F1: 평가·보상 불일치
- F2: 중간관리자 태도·역량
- F3: 역할·책임 불명확
- F4: 교육-업무 연결 부족
- F5: 시간·리소스 압박

### 6.2 점수 변환
- 5점 척도 순방향: `(6 - answer) * 20`
- 5점 척도 역방향: `answer * 20`
- 객관식: 선택지별 미리 정의된 점수 부여

### 6.3 레이어 가중치
- 경영진: 0.75
- 중간관리자: 1.30
- 실무자: 1.20

### 6.4 갭 가점
- exec vs staff 목표 명확성 갭 ≥ 1.5 → F3 +12
- exec vs manager 적극성 갭 ≥ 1.5 → F2 +15
- manager vs staff 지원 인식 갭 ≥ 1.5 → F2 +10

### 6.5 회사 맥락 배수
- ax_stage = education_tools → F1, F2 ×1.15
- ax_stage = partial_apply → F3, F4 ×1.12
- size = 300~2000명 → F2 ×1.10
- 기타 규칙은 이전 상세 문서 참고
- 최종 점수는 min(100, score)

### 6.6 우선순위 결정
조정된 Friction 점수 내림차순으로 상위 3~4개를 Work Redesign 영역으로 매핑

## 7. 경영진용 한 장 리포트 템플릿

**구조**
1. 현재 상태 한 줄 (ax_stage + top friction + size 반영)
2. 핵심 구조적 문제 2~3개 (Friction별 고정 문장)
3. 권고 방향 (교육 추가 아닌 재설계 우선)
4. 역할 분담 제안
5. 다음 30일 액션 2~3개 (우선순위별 구체 액션)

(상세 문장 템플릿은 이전 대화의 “리포트 문장 템플릿 상세화” 참고)

---

## 8. 개인 결과 템플릿

- 한 줄 요약: 역할 + 주요 마찰에 따라 선택
- 내가 느낀 마찰 요인: 개인 응답 기준 상위 2~3개
- 바로 적용 가능한 액션: 역할 + 마찰에 매핑된 구체 액션 2개

---

## 9. 액션 템플릿 (고도화) + 실행 지표

### 경영진 30일 액션
- 누가 / 무엇을 / 언제까지 / 산출물이 무엇인지 명확히 정의
- 실행 여부 지표 (Did) + 효과/진행 지표 (Result) 함께 정의

### 개인 마이크로 액션
- 부담이 낮은 즉시 실행 가능한 행동
- 스스로 체크할 수 있는 Y/N 또는 간단한 기록 지표

---

## 10. 지표 자동 수집 방법 (MVP)

**원칙**: 완벽한 자동화보다 반자동 + 최소 수동

| 구분 | 방법 |
|------|------|
| 경영진 액션 | 노션/시트 액션 보드 + 주기적 체크인 (완료 Y/N + 산출물 링크) |
| 개인 액션 | 결과 화면 체크리스트 (상태 저장) + 익명 실천률 집계 |
| 효과 지표 | 초간단 펄스 설문 + 사례 카운트 |
| 자동화 | 진단 완료 시 액션 보드 카드 자동 생성 수준 (Zapier/Make 또는 간단 백엔드) |

초기에는 “완료율” 중심으로 운영하고, 상세 생산성 수치는 나중에 추가.

---

## 11. 개발 시 권장 사항

1. 결과 로직은 **1차 순수 규칙 기반**으로 정확하게 구현
2. 모든 Friction 점수는 0~100으로 정규화
3. 회사 맥락이 한 줄 진단과 우선순위에 실제로 반영되어야 함
4. 디자인은 화려함보다 **정보 전달력과 신뢰감** 우선
5. HR이 경영진 회의 자료로 바로 쓸 수 있는 톤 유지
6. “직원 탓”이 아닌 “시스템 문제”로 프레이밍
