# 05. Results Structure & Screen Flow (고도화 전체 업데이트)

## 1. 전체 화면 흐름

1. **랜딩**
2. **회사 맥락 입력** (신규)
3. **역할 선택**
4. **진단 진행**
5. **개인 결과**
6. **조직 결과** (핵심)
   - 맥락 반영 한 줄 진단
   - Friction Map
   - Work Redesign 우선순위 (구체화)
   - 경영진용 한 장 리포트
   - HR 활용 가이드

---

## 2. 화면별 구조 + 핵심 카피

### ① 랜딩
**헤드라인**  
교육을 더 시키는 대신,  
**왜 안 바뀌는지부터** 진단하세요

**서브**  
중견기업 HR이 경영진의 AX 지시를  
실행 가능한 과제로 바꾸고,  
조직 마찰을 데이터로 보여주며,  
부서 간 책임을 나눌 수 있게 하는 근거 기반 도구

**CTA**  
- 조직 진단 시작하기  
- 데모 결과 보기

### ② 회사 맥락 입력
**제목**  
먼저 우리 회사 상황을 알려주세요  
(결과에 반영됩니다)

**입력 항목**
- 업종: 제조 / 서비스 / IT·플랫폼 / 유통·물류 / 기타
- 직원 규모: 300명 미만 / 300~1,000명 / 1,000~2,000명 / 2,000명 이상
- 현재 AX 진행 단계: 아직 시작 전 / 교육·도구 도입 중 / 일부 현업 적용 중 / 전사 확산 시도 중
- AX를 주로 추진하는 조직: HR / 경영기획·전략 / IT / TFT·전담조직

### ③ 역할 선택
**제목**  
어떤 역할로 진단에 참여하시나요?

**선택지**  
경영진 / 임원 · 중간관리자 (팀장급) · 실무자

### ④ 진단 진행
- 상단: 역할 + 진행률
- 한 화면 1문항
- 5점 척도 또는 객관식

### ⑤ 개인 결과
**구성**
- 한 줄 요약 (역할 + 주요 마찰 반영)
- 내가 느낀 주요 마찰 요인 2~3개
- 바로 적용 가능한 마이크로 액션 2개 (실행 지표 포함)
- 버튼: 조직 전체 결과 보기

### ⑥ 조직 결과 (핵심 화면)

**상단 한 줄 진단** (회사 맥락 반영)  
예: “교육과 도구 도입은 진행 중이나, 중간관리자 층과 평가 체계에서 구조적 마찰이 크게 나타나고 있습니다. 300~1,000명 규모 중견기업에서 자주 관찰되는 패턴입니다.”

**섹션 1. Friction Map**  
주요 구조적 장벽 TOP 5 (점수 + 시각화)  
- 평가·보상 불일치  
- 중간관리자 태도·역량  
- 역할·책임 불명확  
- 교육-업무 연결 부족  
- 시간·리소스 압박

**섹션 2. Work Redesign 우선순위**  
카드 3~4개. 각 카드에 반드시 포함:
- 우선 영역명
- 왜 지금 이 영역인지 (진단 근거)
- 추천 파일럿 형태
- 관련 역할 분담 (HR / 팀장 / IT)
- 간단한 성공 지표 (실행 지표)

**섹션 3. 경영진용 한 장 리포트**  
미리보기 + PDF 다운로드  
구성:
1. 현재 상태 한 줄 요약
2. 핵심 문제 2~3개 + 근거
3. 권고 방향 (교육 추가 아닌 것)
4. 역할 분담 제안
5. 다음 30일 액션 2~3개 (실행 지표 포함)

**섹션 4. HR 활용 가이드**  
1. 경영진에게 이렇게 이야기하세요 (핵심 메시지)
2. 내부 논의 순서 제안
3. 작은 파일럿을 걸 위치 제안

## 3. 결과물 상세 구성

### Friction Map
- 5개 요인 점수 (0~100)
- 레이어 가중치 + 갭 가점 + 회사 맥락 배수 반영
- 시각화: 가로 막대 또는 점수 카드

### Work Redesign 우선순위 카드 필수 요소
- 영역명
- 진단 근거 1줄
- 추천 파일럿 형태
- 역할 분담
- 성공/실행 지표

### 경영진용 리포트
- 템플릿 기반 생성
- 회사 맥락과 Top Friction이 문장에 반영
- 30일 액션에 “누가 / 무엇을 / 산출물 / 확인 방법” 포함

### 개인 결과
- 역할별 요약 문장
- 개인 마찰 요인
- 마이크로 액션 + 스스로 체크 가능한 실행 지표

---

## 4. 지표 수집 (MVP)

- 경영진 액션: 액션 보드 + 주기적 체크인 (완료 Y/N + 산출물 링크)
- 개인 액션: 결과 화면 체크리스트 + 익명 실천률 집계
- 효과 지표: 초간단 펄스 + 사례 카운트

---

## 5. 카피 원칙
- “교육”보다 “구조적 장벽”, “재설계”, “책임 분담”, “근거”를 전면에
- HR이 경영진 앞에서 바로 쓸 수 있는 톤
- 비난이 아닌 “시스템 문제”로 프레이밍
- 회사 맥락이 결과에 드러나야 함
