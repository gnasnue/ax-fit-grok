# 04. Diagnostic Questionnaire (MVP)

진단은 **3개 레이어**로 구성. 각 레이어 8~12문항으로 응답 부담을 최소화.

## A. 경영진 / 임원 레이어 (8문항)

1. 우리 회사의 AX 추진 목표는 명확하다. (1~5점)
2. AX를 통해 기대하는 가장 중요한 성과는? (생산성 향상 / 비용 절감 / 의사결정 속도 / 신규 사업 / 기타)
3. 현재 AX 추진에서 가장 큰 장애물은? (복수 선택: 직원 수용성 / 중간관리자 태도 / 데이터·시스템 / 예산·인력 / 명확한 목표 부재)
4. AI 도입 후 업무 방식이나 역할이 실제로 바뀌고 있다고 생각하는가? (1~5점)
5. HR이 AX 관련 의사결정에 충분히 참여하고 있다고 보는가? (1~5점)
6. 중간관리자들이 AX를 적극적으로 이끌고 있다고 생각하는가? (1~5점)
7. AX 성과를 어떤 지표로 주로 보고 있는가? (교육 이수율 / 도구 사용률 / 생산성 지표 / 비용 절감 / 아직 명확하지 않음)
8. 향후 1년 내 가장 우선적으로 바꾸고 싶은 영역은? (업무 프로세스 / 역할·직무 / 평가·보상 / 조직 구조 / 역량 체계)

## B. 중간관리자 (팀장) 레이어 (10문항)

1. 우리 팀에서 AI를 업무에 실제로 활용하는 비중은? (1~5점)
2. AI를 더 활용하지 못하는 가장 큰 이유는? (시간 부족 / 어떻게 적용할지 모름 / 평가에 반영 안 됨 / 상사·동료 태도 / 권한·데이터 부족)
3. 회사의 AX 방향이 우리 팀 업무와 잘 연결되어 있다고 느끼는가? (1~5점)
4. 팀원들에게 AI 활용을 독려하는 것이 부담스럽다. (1~5점)
5. AI를 잘 쓰는 팀원과 그렇지 않은 팀원을 다르게 평가하거나 지원하고 있는가? (1~5점)
6. 현재 성과 지표가 AI 활용을 장려하는 방향인가? (1~5점)
7. 팀 업무 중 AI로 대체하거나 보조하면 좋겠다고 생각하는 업무가 있는가? (1~5점)
8. AX 관련 교육을 받은 후 실제 업무 방식이 바뀌었는가? (1~5점)
9. 윗선에서 AX에 대해 기대하는 바와 현장 현실이 다르다고 느끼는가? (1~5점)
10. 팀장으로서 AX를 이끌기 위해 가장 필요한 지원은? (명확한 지표 / 시간 확보 / 교육보다 실행 가이드 / 경영진의 일관된 메시지 / 도구 접근성)

## C. 실무자 레이어 (10문항)

1. 평소 업무에서 AI 도구를 얼마나 사용하는가? (1~5점)
2. AI를 사용할 때 가장 큰 어려움은? (무엇을 시켜야 할지 모름 / 결과가 신뢰 안 됨 / 시간이 더 걸림 / 보안에 대한 걱정 / 특별한 어려움 없음)
3. 회사의 AI/AX 관련 교육이 실제 업무에 도움이 되었는가? (1~5점)
4. AI를 잘 활용하는 것이 나의 평가나 보상에 영향을 준다고 생각하는가? (1~5점)
5. 상사가 AI 활용을 실제로 장려한다고 느끼는가? (1~5점)
6. AI 때문에 내 일이 줄어들거나 역할이 바뀔 것 같아 불안하다. (1~5점)
7. 현재 업무 중 AI의 도움을 받으면 확실히 좋아질 것 같은 부분이 있는가? (1~5점)
8. AI를 더 잘 쓰고 싶어도 여건이 안 되는 이유는? (시간 부족 / 도구 접근 제한 / 상사의 관심 부족 / 어떻게 적용할지 모름 / 필요를 못 느낌)
9. 회사에서 AI를 도입하는 목적이 명확하게 전달되고 있다고 생각하는가? (1~5점)
10. AX가 성공적으로 진행되려면 가장 먼저 바뀌어야 할 것은? (평가 방식 / 상사의 태도 / 업무 프로세스 / 교육 내용 / 도구 자체)
