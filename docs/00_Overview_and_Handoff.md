## 핵심 요약
- **제품**: 중견기업 HR을 위한 AX 조직 마찰 진단 + 업무 재설계 의사결정 지원 시스템
- **Value Proposition**: 경영진의 AX 지시를 실행 가능한 과제로 구조화하고, 조직 마찰을 데이터로 보여주며, 부서 간 책임을 나눌 수 있게 하는 근거 기반 도구
- **MVP 핵심**: 회사 맥락 입력 + 3레이어 진단 + Friction Map + Work Redesign 우선순위 + 경영진 한 장 리포트 + 개인 액션 + 실행 지표
